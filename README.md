# Healthcare Predictive Analytics: Patient Readmission Risk Prediction

## Overview
Developed for the **IBM SkillsBuild Data Analytics with AI Academic Internship Program** (AICTE | BharatCares).

This project uses AI and Machine Learning to predict 30-day hospital readmission risks based on clinical indicators, lab results, and patient history.

## Project Structure
- `GurucharanKapale_HealthcareAnalytics_AI.ipynb`: Complete Jupyter Notebook code and visualization pipeline.
- `GurucharanKapale_ProjectReport.docx`: Detailed project documentation report.
- `requirements.txt`: Python dependencies.
- `README.md`: Setup instructions and project summary.
